## H.I.S. Future 0.1.5

### Highlights for testers

- Added one protected primary Project Node to every Vault, with a reusable first capability for rich-text content.
- Closing a Vault now returns to Home after its SQLite and resources are durable; rebuilding the portable `.his` continues safely in the background.
- You can open and use another Vault while the previous one is packaging. Reopening the same Vault waits only for its own sync, preventing races.
- Ctrl+S now flushes the durable working state without forcing a full synchronous archive rebuild.

### Archive safety

- `.his v1` remains the official portable format and is replaced only after a temporary archive has been completed and validated.
- Failed archive updates preserve the previous valid `.his`, retain the newer durable working copy, remain visibly dirty, and can be retried.
- Explicit Exit waits for pending archive work and refuses to pretend success if synchronization fails. Closing the window with X still hides the live workspace to the tray.

### Graph improvements

- Added directional arrows and inspectable semantic facts for relations and mentions.
- Improved selection focus, edge interaction, smooth level-of-detail transitions, node entrance/removal animation, and creation from the Graph context menu.
- Visually identifies the primary Project Node without changing graph forces or persisted relation semantics.

### Alpha note

H.I.S. Future remains early Alpha software. Test with backups and do not use this build as the only copy of critical information.
