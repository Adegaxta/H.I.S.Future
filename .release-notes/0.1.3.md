## H.I.S. 0.1.3

### Improvements
- Added the current H.I.S. version to Project Settings for easier build identification.
- Improved the release process with automated validation, signing, packaging, and publishing.
- Release notes are now reviewed locally before publication and preserved exactly in each release.

### Technical
- Added a tag-driven GitHub Actions release pipeline.
- Releases are built and verified as drafts before becoming public.
- Added automatic validation for version consistency, updater artifacts, signatures, and `latest.json`.
- Added a simplified local release command with explicit confirmation before publishing.
