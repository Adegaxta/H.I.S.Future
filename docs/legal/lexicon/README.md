# HIS Lexicon — estado legal

Se realizó una importación local aprobada fuera del repositorio, en `../.his-lexicon-data/`. Ningún dataset externo está incorporado o empaquetado en el build. Esta carpeta registra obligaciones antes de una posible distribución. La matriz operativa está en `docs/lexicon/dataset-manifest.json`.

Los artefactos futuros deben permanecer separados por provider. Una fila generada debe conservar `source`, versión, licencia y atribución. No se permite fusionar la procedencia en un campo genérico ni presentar datos de terceros bajo las licencias propias de HIS.
