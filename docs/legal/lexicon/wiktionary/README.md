# Wiktionary / Kaikki

Estado: importado localmente; no incluido ni redistribuido con HIS.

- Origen previsto: dump de Wiktionary transformado por Wiktextract y publicado por Kaikki.org.
- Datos: bajo las licencias indicadas por Wiktionary/Kaikki, CC BY-SA y GFDL.
- Derivado previsto: SQLite filtrado a lemma, forms, POS, synonyms y translations. Se descartan etimologías, pronunciaciones, citas, ejemplos históricos, audio, plantillas, logs y errores.
- Distribución: mantener atribución, enlace/origen, fecha del dump, indicación de modificaciones y los textos/avisos exigidos. El derivado de datos debe mantenerse identificable y separado; las obligaciones share-alike aplicables no se trasladan por declaración al código original de HIS.
- `Third Party Notices`: identificar Wiktionary contributors, Kaikki/Wiktextract, dump/fecha, cambios de filtrado y licencias.

Antes de descargar se deben fijar URL directa, bytes y SHA-256 en el manifiesto y obtener aprobación del usuario.
