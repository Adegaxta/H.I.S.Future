# Internacionalización

La infraestructura vive en `src/i18n`. `core.ts` es el dueño del idioma base, los locales admitidos, los catálogos y la resolución de claves; `persistence.ts` valida y almacena preferencias; `LocaleContext.tsx` conecta esa infraestructura con React y con el ajuste SQLite del proyecto.

## Añadir o cambiar texto

1. Elige el catálogo del dominio en `src/i18n/catalogs/es` y añade una clave semántica al objeto español. Home, shell, editor, vistas nodales, Defs nodales, settings, workspace y changelog tienen archivos propios.
2. Añade la misma clave al catálogo inglés equivalente. `EN_TRANSLATIONS` usa `satisfies TranslationCatalog`, por lo que la compilación detecta claves ausentes.
3. Consume la clave exclusivamente desde la API pública `src/i18n`: `const { t } = useLocale()` y `t("dominio.concepto")`. Para parámetros usa marcadores como `{count}` y pasa un objeto a `t`.

Las claves siguen `dominio.sección.concepto` y describen intención, por ejemplo `common.actions.delete` o `calendar.views.week`. No se crean claves opacas como `label1`, ni se duplican frases comunes.

## Añadir un idioma

Añade el locale a `SUPPORTED_LOCALES`, crea los catálogos paralelos y regístralos en `translations.ts` y `CATALOGS`. Español (`es`) es el idioma base, predeterminado y fallback determinista. Los valores desconocidos o antiguos se ignoran y vuelven a español.

## Integrar un Node o comando nuevo

El ID interno y persistido nunca contiene presentación localizada. Un Node declara `type`, `labelKey` y `nodeNameKey` en `src/defs/nodeTypes.ts`; la UI resuelve esas claves con `t`. Los comandos `/` siguen el mismo contrato mediante `labelKey` y `categoryKey`. No se compara lógica contra etiquetas traducidas.

No se internacionalizan nombres de proyectos o Nodes creados por el usuario, contenido del editor, descripciones libres, URLs, metadata libre, IDs, tags, extensiones ni formatos persistidos. Los nombres predeterminados que ya se guardan como datos tampoco deben cambiarse sin una migración de producto explícita.
