# H.I.S. Future

**H.I.S. Future (HIS)** is a local-first modular workspace for creating, organizing, and connecting information.

HIS is currently in **early Alpha** and under active development.

> Keep backups of important projects and do not use Alpha builds as the only copy of critical information.

## Current status

HIS currently targets **Windows x64**.

The project is built with Tauri, React, TypeScript, Rust and SQLite, with a local-first approach. Projects are stored as `.his` files.

Official builds are available through [GitHub Releases](../../releases).

## Philosophy

HIS is built around modular information rather than prescribing a single structure for notes, projects or knowledge.

The system provides specialized nodes and relationships between them; the user decides how those pieces are composed.

Core principles:

- Local-first
- Modular by design
- User-owned project files
- Interoperable node types
- Quality-of-life over unnecessary complexity

## Alpha

HIS is still evolving rapidly.

Interfaces, node behavior and internal architecture may change between Alpha versions. Backwards compatibility and project safety are treated as important development priorities, but Alpha builds should still be used with appropriate backups.
